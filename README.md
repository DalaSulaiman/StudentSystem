# Student Management System 

A robust, Java-based console application built to manage student records efficiently using Core OOP principles, Custom Exception Handling, and File I/O for data persistence.

---
![alt text](< Student Management Dashboard.png>)


## 🌟 Key Features

* ➕ **Add Student:** Register new students with real-time validation (Unique ID, Alphabetic Name, GPA 0.0–5.0).
* 📋 **Formatted Table Display:** View records in a clean, aligned ASCII table.
* 🔍 **Search Student:** Find records by ID using custom error handling.
* ✏️ **Update Student Details:** Modify existing student names or GPAs dynamically.
* 🗑️ **Delete Student:** Remove student records with automatic file synchronization.
* 📊 **System Statistics:** View overall student count, highest GPA, lowest GPA, and system average.
* ↕️ **Sort Records:** Sort students by GPA in descending order (highest to lowest).
* 💾 **Data Persistence:** Automatically saves and loads records via `students.txt`.
* 🛡️ **Custom Exception Handling:** Utilizes `StudentNotFoundException` for clean error reporting.

---

## 🛠️ Tech Stack & Concepts

* **Language:** Java (JDK 17+)
* **Data Structures:** `ArrayList`
* **File I/O:** `PrintWriter`, `Scanner`, `File`
* **OOP Principles:** Encapsulation, Custom Exceptions, Separation of Concerns
* **Version Control:** Git & GitHub
